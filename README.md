# DataLearn Portfolio Project Lessons

Self-paced project lessons for students who want to rebuild production-style data science, data engineering, analytics, NLP, MLOps, and database projects without needing a live teacher.

This repository is a curriculum resource. It is not tagged or presented as one of Isaac Asiedu's resume projects.

## How Students Should Use This Repo

Each lesson is designed to be completed slowly and actively. Do not read it like an article. Build the project step by step, run the code, answer the reflection questions, complete the exercises, and only then move to the next module.

A good student workflow:

1. Read the learning goals.
2. Create a clean project folder.
3. Type or adapt each code block.
4. Run every command.
5. Complete every practice task.
6. Compare your result with the expected output.
7. Complete the final assignment.
8. Push your finished project to your own GitHub repo.

## Teaching Philosophy

The goal is not memorization. The goal is project fluency.

Students should finish each lesson able to explain:

- What business problem the project solves
- What real dataset was used
- How the data was cleaned or modeled
- Why the code is structured the way it is
- How to run the project locally
- How to test it
- How to describe the project in a portfolio or interview

## Required Student Skills

Students should be comfortable with:

- Basic Python
- Basic command line usage
- Creating folders and files
- Installing packages with `pip`
- Reading error messages patiently

Each lesson explains the project-specific concepts from scratch.

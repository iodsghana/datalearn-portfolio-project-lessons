# Student Project Checklist

Use this before you submit or publish your finished project.

## Code

- [ ] The project runs from a clean environment.
- [ ] `requirements.txt` includes all needed packages.
- [ ] Scripts are organized into clear folders.
- [ ] File names are readable.
- [ ] Code comments explain difficult parts, not obvious lines.

## Data

- [ ] The dataset is real and external.
- [ ] The source link is included in the README.
- [ ] Raw data is not committed if it is too large.
- [ ] Cleaned or sample data is included only when appropriate.
- [ ] Data cleaning choices are explained.

## Testing

- [ ] Tests run successfully.
- [ ] Tests check data quality.
- [ ] Tests check important project logic.
- [ ] API tests are included if the project has an API.

## Documentation

- [ ] README explains what the project does.
- [ ] README includes setup steps.
- [ ] README includes how to run tests.
- [ ] README includes project structure.
- [ ] README includes limitations.

## Portfolio Readiness

- [ ] The GitHub repo is public if you want recruiters to see it.
- [ ] The project has a clear business problem.
- [ ] The project has measurable outputs.
- [ ] You can explain the hardest technical decision in an interview.

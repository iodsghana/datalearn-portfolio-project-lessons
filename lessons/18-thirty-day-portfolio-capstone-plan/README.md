# Lesson 18 - 30-Day Portfolio Capstone Plan

In this lesson, you will organize the full curriculum into a realistic 30-day self-paced plan.

The goal is not to rush. The goal is to finish with a portfolio that has real projects, strong documentation, tests, deployment evidence, governance notes, communication artifacts, and interview practice.

## Learning Goals

By the end of this lesson, you should be able to:

- Choose the right project sequence for your goals
- Plan weekly deliverables
- Track progress honestly
- Review and polish projects
- Prepare GitHub and resume materials
- Practice interview explanations
- Complete a final portfolio review

## Who Should Use This Plan

Use this plan if you want to build a job-ready portfolio in a structured way.

You can adapt it for:

- Data scientist roles
- Data engineer roles
- ML engineer roles
- Analytics engineer roles
- Instructor-led student cohorts

## Module 3 - Week 1: Build Core Technical Projects

Goal: complete one or two strong technical projects.

Recommended schedule:

| Day | Focus |
| --- | --- |
| 1 | Choose track, clone/create repos, read README requirements |
| 2 | Build data ingestion and validation |
| 3 | Build feature engineering or ETL |
| 4 | Train model or build analytics outputs |
| 5 | Add API or dashboard outputs |

- Data source is documented

## Module 9 - Avoid Burnout

A portfolio plan should be sustainable.

Rules:

- Do not build all night
- Do not start new projects before finishing core ones
- Do not chase every tool
- Do not hide broken steps
- Do not compare your day 3 to someone else's year 3

Good daily rhythm:

```text
30 minutes reading
90 minutes building
30 minutes testing
30 minutes documenting
15 minutes reflection
```

# Curriculum Guidelines

This repository is for self-paced instruction, not resume branding.

## Lesson Standard

Every lesson should help a student rebuild the finished project without live teacher support.

A lesson is complete only when it includes:

- Real external dataset source
- Plain-English business problem
- Setup instructions
- Step-by-step build modules
- Exercises inside each module
- Practice tasks
- Checkpoint questions
- Common mistakes
- Final assignment
- Rubric
- Interview practice questions

## Writing Style

Use simple explanations. Avoid assuming that students already understand production engineering terms.

Good:

> An index helps MongoDB find matching documents faster. Without an index, MongoDB may need to scan every document in the collection.

Less helpful:

> Create an optimized compound index for query efficiency.

## Repository Rule

Do not add this repo to the `iodsghana` profile README as a featured resume project. It is a teaching asset.
